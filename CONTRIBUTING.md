## ⚡ Cara Cepat Mengambil Tugas (Claim an Issue)
1. Buka tab **[Issues](https://github.com/rezadesky/yabatpresensi/issues)**.
2. Pilih salah satu tugas yang berlabel **`good first issue`** atau **`help wanted`**:
   - 📍 **[Issue #4: Peningkatan Akurasi GPS](https://github.com/rezadesky/yabatpresensi/issues/4)**
   - 📝 **[Issue #5: Fitur Pengajuan Izin / Cuti](https://github.com/rezadesky/yabatpresensi/issues/5)**
   - ✨ **[Issue #6: Modernisasi UI/UX Mobile](https://github.com/rezadesky/yabatpresensi/issues/6)**
   - 📊 **[Issue #2: Export Laporan CSV/Excel](https://github.com/rezadesky/yabatpresensi/issues/2)**
3. Tulis komentar singkat di issue yang ingin Anda kerjakan: *"Halo, saya ingin mengerjakan tugas ini!"*.

---

## 🛠️ Langkah Menjalankan Proyek & Mengirim PR

1. **Fork repositori ini** ke akun GitHub Anda.
2. **Clone ke komputer lokal Anda**:
   ```bash
   git clone https://github.com/<username-anda>/yabatpresensi.git
   cd yabatpresensi
   ```
3. **Buat branch baru** untuk fitur yang dikerjakan:
   ```bash
   git checkout -b feat/nama-fitur
   ```
4. **Kembangkan kodenya & Commit**:
   ```bash
   git commit -m "feat: tambahkan fitur pengajuan izin"
   ```
5. **Push ke fork Anda & Buka Pull Request**:
   - Buka halaman PR di GitHub, jelaskan perubahan yang Anda buat, dan cantumkan nomor issue (misal: `Fixes #5`).
